# ClientManagement application dependencies

ClientManagement uses [Riok.Mapperly 4.3.1](https://www.nuget.org/packages/Riok.Mapperly/4.3.1) to generate mapping code at build time. The package is a private build dependency and its runtime assets are excluded.
